# Portafolio personal - Flavia Berzuini

Esta landing page fue desarrollada como entrega final para el **PFO1 de Desarrollo de Sistemas Web (Front End)**. El objetivo principal de este proyecto es presentar un portafolio web interactivo y responsivo que refleje mi identidad profesional, integrando mis habilidades en el desarrollo de software con mi vocación por la educación y la creatividad.

## Tecnologías utilizadas
- **HTML5:** Estructura semántica (uso de `<header>`, `<nav>`, `<section>`, `<footer>`, etc.) para mejorar la accesibilidad.
- **CSS3:** 
  - Implementación de variables CSS (`:root`) para un fácil mantenimiento del tema.
  - Uso intensivo de Flexbox y CSS Grid para la distribución de los componentes.
  - Animaciones y transiciones fluidas (efectos de hover, blobs animados).
  - Diseño 100% responsive adaptado a dispositivos móviles mediante Media Queries.

## Decisiones de diseño y desarrollo
Durante el proceso de maquetación, tomé varias decisiones estratégicas para asegurar un código limpio y una experiencia de usuario (UX) agradable:
1. **Paleta de colores y estética:** Opté por un tema oscuro (`#0B1121`) combinado con tipografías claras y acentos en degradado (violeta y teal) para darle un aspecto tecnológico, moderno y elegante.
2. **Estructura unificada:** Para mantener la coherencia visual, las distintas secciones (Sobre mí, Formación, Intereses, Contacto) se resolvieron mediante "cajas" o tarjetas con un estilo unificado y sombras sutiles que resaltan sobre el fondo general.
3. **Navegación fluida:** Se implementó un menú de navegación fijo con anclajes (`#id`) que permite recorrer la página en una sola vista (formato one-page), facilitando la lectura sin recargas.
4. **Optimización del espacio:** En pantallas pequeñas, elementos como las galerías y la línea de tiempo se colapsan a una sola columna para garantizar la legibilidad y evitar el scroll horizontal.
