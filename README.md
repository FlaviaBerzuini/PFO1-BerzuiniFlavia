# Portafolio personal - Flavia Berzuini

Esta landing page fue desarrollada como entrega final para el **PFO1 de Desarrollo de Sistemas Web (Front End)**. El objetivo principal de este proyecto es presentar un portafolio web interactivo y responsivo que refleje mi identidad profesional, integrando mis habilidades en el desarrollo de software con mi vocación por la educación y la creatividad.

## Tecnologías utilizadas
- **HTML5:** Estructura semántica (uso de `<header>`, `<nav>`, `<section>`, `<footer>`, etc.) para mejorar la accesibilidad.
- **CSS3:** 
  - Implementación de variables CSS (`:root`) para un fácil mantenimiento del tema.
  - Uso intensivo de Flexbox y CSS Grid para la distribución de los componentes.
  - Animaciones y transiciones fluidas (efectos de hover, blobs animados).
  - Diseño 100% responsive adaptado a dispositivos móviles mediante Media Queries.

## Decisiones de diseño y desarrollo
Durante el proceso de maquetación, tomé varias decisiones estratégicas para asegurar un código limpio y una experiencia de usuario (UX) agradable:
1. **Paleta de colores y estética:** Opté por un tema oscuro (`#0B1121`) combinado con tipografías claras y acentos en degradado (violeta y teal) para darle un aspecto tecnológico, moderno y elegante.
2. **Estructura unificada:** Para mantener la coherencia visual, las distintas secciones (Sobre mí, Formación, Intereses, Contacto) se resolvieron mediante "cajas" o tarjetas con un estilo unificado y sombras sutiles que resaltan sobre el fondo general.
3. **Navegación fluida:** Se implementó un menú de navegación fijo con anclajes (`#id`) que permite recorrer la página en una sola vista (formato one-page), facilitando la lectura sin recargas.
4. **Optimización del espacio:** En pantallas pequeñas, elementos como las galerías y la línea de tiempo se colapsan a una sola columna para garantizar la legibilidad y evitar el scroll horizontal.

## Declaración de uso de Inteligencia Artificial
Detallo a continuación el uso específico de herramientas de Inteligencia Artificial (todas utilizadas en sus planes gratuitos o de uso libre) durante el desarrollo de este proyecto.
Toda esta experiencia práctica es el resultado directo de mi formación continua en plataformas de inteligencia artificial generativa, la cual detallo en la sección de Formación de este portafolio. El estudio profundo y el trabajo previo me brindaron el criterio técnico necesario para esta entrega. Esto me permitió no depender de los resultados automáticos "por defecto" de las herramientas, sino dirigir a los modelos de forma intencional, ajustar los parámetros precisos y refinar cada diseño con un propósito claro.
*   **ChatGPT (OpenAI):** 
    *   **Uso:** Edición y fotomontaje de mi foto de perfil.
    *   **Intervención personal:** A través de ingeniería de prompts específicos, le indiqué al modelo que reemplazara el fondo original y adaptara la vestimenta para lograr un tono más profesional. Evalué diferentes generaciones, seleccioné la más adecuada y validé que mantuviera naturalidad.
*   **HeyGen:** 
    *   **Uso:** Generación de la fotografía ilustrativa para la sección del proyecto de podcast.
    *   **Intervención personal:** Configuré los parámetros base de la plataforma para asegurar que el estilo visual se alineara con la estética general del portafolio, descartando resultados que parecieran excesivamente sintéticos.
*   **IA de diseño (Ecosistema Krea AI / Stable Diffusion / Canva):** 
    *   **Uso:** Conceptualización y generación del logo principal de la cabecera.
    *   **Intervención personal:** No utilicé la imagen en crudo generada por la IA. La utilicé como base conceptual que luego intervine, vectoricé y ajusté utilizando herramientas de diseño gráfico específicas para integrarle los colores de la paleta del proyecto (violeta y teal) y asegurar su escalabilidad.
*   **Gemini (Google):** 
    *   **Uso:** Asistente de programación (Pair Programming) para la maquetación.
    *   **Intervención personal:** Definí toda la estructura base y el diseño de forma autónoma. Consulté a la IA específicamente para refactorizar bloques extensos de CSS, depurar problemas de alineación en flexbox, revisar el colapso del menú hamburguesa en mobile y verificar que el uso de etiquetas cumpliera al 100% con la semántica de HTML5. Yo audité e integré manualmente cada línea de código sugerida.
